# Seed Show — Modrinth draft

**Title:** Seed Show
**Description:** Replies with the world seed.
**Command:** `/seedshow`

## Body

Replies with the world seed.

### Usage

`/seedshow` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/seedshow` in chat
